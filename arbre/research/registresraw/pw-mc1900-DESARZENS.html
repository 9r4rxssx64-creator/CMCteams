Recherches à partir de 1900

A partir de 1900, tous les actes sont indexés et les recherches sont possibles par le type d'acte, le nom, le prénom, et/ou la date de l'évènement.
Certains actes d'Etat Civil contenant des informations confidentielles ne sont pas consultables via le site Internet. Il s'agit d'actes qui font apparaître la transcription d'un jugement (jugement de rectification, jugement d'adoption, etc...). Dans ce cas, la recherche aboutira et la personne sera invitée via un message à prendre l'attache auprès de la Mairie de Monaco pour la consultation de l'acte.

Tous les actes sont répertoriés dans des tables alphabétiques.
Ces tables indiquent les nom, prénoms, numéro de l'acte ou numéro de folio. Elles sont consultables dans les registres en fin d'année. 

Nos actes sont payants, le coût d'un acte d'état civil à partir de 1900 est :
- Naissance, décès : 1,00€ ;
- Mariage : 1,50€.
Ensuite, il faut ajouter les frais postaux à ce montant d'actes.
Si vous souhaitez, merci de prendre contact avec le Service Etat Civil :
- soit par appel téléphonique - Tel n° +377.93.15.28.51 ;
- soit nous adresser un courrier accompagné d'un chèque à l'ordre de la "Mairie de Monaco".

Pour faciliter vos recherches, nous avons mis à votre disposition un mode d'emploi que vous trouverez dans la Foire aux Questions.
