# ClayScore — Plan de la vidéo de démonstration
### Script complet · Storyboard · Tournage à l'iPhone · Montage sur tablette

**Deux versions à produire à partir du même tournage** :
- **V-courte (75 s)** — réseaux sociaux, page d'accueil, message aux clubs. Verticale 9:16 + horizontale 16:9.
- **V-détaillée (4-5 min)** — démonstration complète pour les présidents de clubs, la FFBT, Laporte, MonacoTech.

**Important — honnêteté du calendrier** : la vraie vidéo se tourne quand le prototype fonctionne (mois 3-4). C'est elle qui vend. En attendant, une **vidéo concept** (animations de l'interface + plans de stand + voix off) est possible dès maintenant pour MonacoTech et les premiers contacts — même script, sans les plans "produit en marche".

## 2. V-détaillée (4-5 min) — plan des chapitres

1. **Le problème** (30 s) : litiges, comptage papier, éclats invisibles à l'œil.
2. **Installation en temps réel** (60 s, accéléré ×8 avec chrono incrusté) : 3 pods plantés, câbles, allumage → « prêt en 18 minutes ».
3. **Démonstration discipline par discipline** (90 s) : FU puis parcours avec plateau traversant ; chaque verdict montré en double écran (réel + interface).
4. **Le cas ambigu** (40 s) : éclat minuscule → l'interface propose le ralenti → validation d'un tap. Message : « aucun point douteux n'est attribué sans vous ».
5. **Gestion de partie** (40 s) : création d'une partie 4 tireurs, rotation, doublé, no-bird, fiche finale et stats.
6. **Le boîtier** (30 s) : batterie une journée, WiFi local, aucune connexion requise, mode TV club-house.
7. **Appel à l'action** (20 s) : démonstration sur votre stand, contact.

## 3. Tournage — avec ton iPhone (qualité pro sans louer de matériel)

- **Réglages** : 4K 60 fps pour les plans normaux ; **mode ralenti 240 fps** pour toutes les casses de plateaux (c'est LE plan signature — filmer 20-30 casses pour en garder 3) ; verrouiller exposition et focus (appui long) ; jamais de zoom numérique — se rapprocher.
- **Stabilité** : petit trépied + pince smartphone (~25 €) obligatoire pour les plans fixes ; pour les mouvements, stabilisateur DJI Osmo Mobile (~90 €, optionnel mais visible à l'écran).
- **Lumière** : tourner à la golden hour (1re heure / dernière heure de soleil) pour les plans beauté ; éviter midi (ombres dures).
- **Son** : la détonation au micro de l'iPhone sature — enregistrer les tirs à 30-40 m pour l'ambiance, et la voix off séparément au calme (micro-cravate Bluetooth ~30 €, ou dictaphone dans une pièce meublée).
- **Plans d'interface** : enregistrement d'écran natif de la tablette (propre, 60 fps) — pas de filmage d'écran.
- **Checklist de plans** : 5 casses ralenti ciel bleu · 2 casses fond forêt (preuve !) · 1 manqué net · 1 no-bird · installation accélérée · mains sur tablette · 3 visages/réactions de tireurs (avec leur accord écrit — droit à l'image) · plan large du stand au drone si un membre du club en a un.

## 4. Montage — sur ta tablette

- **CapCut** (gratuit, iPad/Android) : suffit largement — coupes, ralentis, textes, transitions, export 4K. Alternative : LumaFusion (~30 €, plus pro, iPad).
- **Voix off** : toi (authenticité du porteur de projet, accent du Sud = sympathie) ou voix IA de qualité (ElevenLabs, ~5 €/mois) si tu préfères.
- **Musique** : uniquement des banques libres de droits avec licence (Uppbeat, Artlist) — jamais un titre commercial, les vidéos se font bloquer.
- **Sous-titres incrustés** (CapCut les génère) : 80 % des vues réseaux sociaux sont sans le son.
- **Habillage** : les surimpressions de verdict (« CASSÉ ✔ » vert, « NO BIRD » orange, trajectoires) s'exportent directement depuis l'interface ClayScore en mode replay — je prévois cette fonction d'export dans le logiciel (elle est ajoutée à la spec Claude Code, jalon 5).

## 5. Diffusion

Version courte : Instagram/Facebook (les clubs y sont très actifs), page du site, signature des mails aux clubs. Version détaillée : YouTube (non répertoriée pour l'envoi ciblé FFBT/Laporte, publique ensuite), démonstrations en concours sur le mode TV.

**Budget vidéo total : 55-145 €** (trépied + micro-cravate, stabilisateur optionnel) — tout le reste est déjà dans ta poche.
